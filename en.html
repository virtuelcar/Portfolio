IIIArtificial intelligence · 2026

Handing repetitive work to AI

Monitoring the news and producing first drafts took five hours per session. I built two connected agents in n8n, with a human review step in between. The same session now takes one hour.

In production

Monitoring and summary agents

The AI collects, sorts and writes a first draft from the sources. I choose the topics, then check and review everything before publication. When a source cannot be read, the agent stops and flags it instead of making things up.

Time per session
5 h → 1 h
Agent 1

Monitoring

  1. Reads the topics already planned by the team, and the history, in Google Sheets
  2. Collects news from the sources through their RSS feeds
  3. Removes duplicates and anything already covered
  4. Claude analyses the news in batches and selects the most relevant items
  5. Sends the selection by email and updates the history
I approve
Choice of topics
Agent 2

Summary

  1. Starts from a webhook and reads the approved topics
  2. Retrieves the source text from the web
  3. Unreadable source: marks the topic to complete and stops
  4. Otherwise, the Claude API writes a first draft following the editorial guidelines
  5. Creates the document in Google Docs for review
  • n8n
  • Claude API
  • Google Sheets
  • Google Docs
  • Gmail
  • RSS
  • Webhook

The same approach works for competitive monitoring, document summaries or reporting.

My method

The one I followed for these two agents

  1. Start from the job

    Observe the real process, measure how long it takes and spot the repetitive steps.

  2. Pick the right tool

    Use AI where it adds something, and a standard workflow where that is more reliable.

  3. Build

    Connect existing tools with n8n and the Claude API, handle errors, document.

  4. Stay in control

    Add human review at the key steps and measure the time saved.
