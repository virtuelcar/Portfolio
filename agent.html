    Comment il fonctionne

    Le code calcule, l'IA interprète, une personne décide

    1 · Webhook

    Le site envoie à n8n l'entreprise choisie et la langue.

    2 · Code

    Validation, quotas, puis calcul de tous les KPI et détection des variations. Aucun chiffre ne vient de l'IA.

    3 · Claude

    Claude Haiku lit les KPI, cherche les causes entre les canaux et rédige la note dans un format imposé.

    4 · Contrôle

    Le code vérifie la structure de la note avant de la renvoyer. En cas d'échec, l'agent le signale au lieu d'inventer.

    En entreprise, la même logique se branche sur les vrais exports (Meta Ads, Google Ads, GA4, outil d'emailing, CRM) et envoie la note chaque lundi par email, Slack ou Google Docs.
