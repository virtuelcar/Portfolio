    How it works

    Code computes, AI interprets, a person decides

    1 · Webhook

    The site sends n8n the chosen company and the language.

    2 · Code

    Validation, usage limits, then every KPI is computed and changes are detected. No figure comes from the AI.

    3 · Claude

    Claude Haiku reads the KPIs, looks for causes across channels and writes the note in a fixed structure.

    4 · Check

    Code checks the note's structure before sending it back. If something fails, the agent says so instead of making things up.

    In a company, the same logic plugs into the real exports (Meta Ads, Google Ads, GA4, email tool, CRM) and sends the note every Monday by email, Slack or Google Docs.
